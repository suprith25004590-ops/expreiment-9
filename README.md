## Program 9.2 – Matplotlib and Pandas

### Aim
To implement Matplotlib and Pandas libraries in Python and visualize student data using different charts.

### Algorithm
1. Start the program.
2. Import Pandas and Matplotlib libraries.
3. Create a dictionary containing student names, marks, and attendance.
4. Convert the dictionary into a DataFrame.
5. Display the student database.
6. Create a bar chart to display student marks.
7. Create a line chart to display student marks.
8. Create a pie chart to represent student marks.
9. Create a scatter chart to compare attendance and marks.
10. Create a histogram to display the distribution of marks.
11. Display all the charts.
12. Stop the program.
